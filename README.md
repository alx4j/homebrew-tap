# AI4J Homebrew tap

This is the official public Homebrew tap for [AI4J](https://github.com/alx4j/ai4j).

Install AI4J on Apple Silicon macOS with:

```sh
brew install alx4j/tap/ai4j
```

The formula installs the public `v1.0.0` release and verifies its SHA-256 checksum. Intel macOS, Linux, and Windows are not supported by this tap formula.
