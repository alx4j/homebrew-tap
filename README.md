# AI4J Homebrew tap

This is the public Homebrew tap for [AI4J](https://github.com/alx4j/ai4j).

No formula is published yet. A stable formula requires an immutable, publicly downloadable AI4J release binary and its SHA-256 checksum. The formula will be added after those assets are available.

Once the first formula is published, install AI4J with:

```sh
brew install alx4j/tap/ai4j
```
